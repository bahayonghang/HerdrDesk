# HD-035 最终安全与许可审查

## 目标与依据

对实际候选发布产物做独立安全和许可审查，覆盖 NuGet/npm/Cargo、native host、RPC/SSH/filehelper 及诊断导出。原任务 `tasks/HD-035.md:7`；原 AC02/43/44 见 `tasks/HD-035.md:21`。现有许可登记仍有未决项，见 `docs/licensing-register.md:14`。

## 需求

- **R1 来源与发行权**：每项直接/间接依赖、JS/字体/图标/sidecar/运行时都有版本、来源、license/NOTICE 和打包范围记录；HerdDesk 项目许可与 Publisher 有维护者决定，不复用未授权 herdrm 内容。
- **R2 漏洞与可达性**：扫描实际锁定依赖，记录工具版本、数据库日期和执行结果；确认可利用的 Critical/High 必须为零，扫描失败/缺包不能记为零。
- **R3 特权边界**：真实产品中 renderer、终端输出、文件名、深链接不能任意执行进程、读取文件、绕过 host 控制权或切换发送目标；普通用户运行。
- **R4 凭据与数据**：日志、argv、崩溃材料和用户预览导出不含 secret/终端正文/剪贴板/文件内容；缓存淘汰只作用于自身授权范围。
- **R5 证据闭环**：审核最终包与最终 SHA；安全修复后复测影响面并重新绑定产物 hash，未解决问题阻断 stable。

## 前置依赖与边界

原依赖 HD-006/031/034；具体目录 `.trellis/tasks/09-08-windows-hd-006`、`.trellis/tasks/09-08-windows-hd-031`、`.trellis/tasks/09-08-windows-hd-034`。最终审查另要求 HD-032 文件攻击和 HD-033 资源/可访问性候选证据。

本任务是验证与风险处置，不新增业务功能。安全修复若改变已有 task 契约，回到该 task 修订方案；不能借安全审查构建通用规则引擎、收集用户历史会话或扩大凭据访问。

## 子任务验收

- [ ] **AC1（R1；汇总原 AC02）**：最终包中的每种依赖/资产与来源清单一一对应；所需 LICENSE/NOTICE 随包，未决定的授权项目数为零，禁止将“公开可读”作为复用依据。
- [ ] **AC2（R2；原 AC43）**：每个生态扫描成功或有明确未覆盖项；已确认可利用 Critical/High 为零，其他风险例外有维护者决定、理由和到期，不用例外隐藏已确认可利用严重问题。
- [ ] **AC3（R3；汇总原 AC44）**：恶意 host 消息/origin/旧 epoch/通知参数/文件名实验不能越权，记录实际进程和访问观察，不能仅查看 allowlist 字符串。
- [ ] **AC4（R4）**：使用合成 canary 凭据与正文触发失败/导出，默认可见日志与包中无 canary；用户预览和删减导出可用。
- [ ] **AC5（R5）**：单一最终审查报告记录版本、SHA、artifact hash、扫描日期、复现步骤、失败项和结论；HD-036 能据此决定候选是否可发布，未测项仍 UNVERIFIED。
