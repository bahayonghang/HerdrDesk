# HD-013 · TerminalCliTransport与生命周期

状态：`planned`。阶段：P2。预计有效人日：2–3。

## 目标与范围

实现长期CLI进程、单reader、stdin串行写、stderr、退出原因。

拟建/修改产物：`HerdDesk.Infrastructure/Terminal`。这是目标仓库路径，不表示本包已包含实现。

先读取相关ADR与原始证据，明确测试fixture是合成还是真机；先建立/确认本任务记录再修改代码。采用最小可验证改动，业务逻辑不绕过Core策略；新增行为需配测试。涉及远端、输入、删除、部署的操作必须使用隔离测试资源。

## 验收

- **AC05**：observe获得可解码完整基线；seq/尺寸/Base64正确；EOF被报告而非冒充pane退出。
- **AC06**：一次输入仅一次到达；resize实际生效；release结束桥但pane继续运行。
- **AC15**：关闭/崩溃GUI后herdr daemon与已有agent继续；不调用server stop或杀进程树中的daemon。

## 风险与回滚

风险：结束桥误伤daemon、阻塞reader。

回滚：禁用control，仅observe。不得以停止用户herdr会话代替应用级回滚。
