# Security status

HerdDesk is at G0 and must not be used as a production terminal controller. No security audit or production readiness is claimed.

Do not attach tokens, private keys, terminal contents, real session snapshots, personal paths or SSH host details to public issues. Reproduce suspected problems with synthetic data or an isolated disposable session. Until a private reporting channel is configured, do not publish sensitive exploit details or secrets in a public issue.

All actual control/input experiments require disposable targets and explicit consent. No default takeover, daemon lifecycle operation, remote helper installation or input retry is permitted. Closing a diagnostic child process must not terminate the daemon or an agent. Real Windows ACL, IME and ownership behavior remains unverified.
