# HD-034 签名、安装与更新回滚

## 目标与依据

把经过验收的 HerdDesk 构建交付为可安装、可更新、可退回的签名 Windows 包；应用升级期间已有 herdr pane 继续存活。原始任务 `tasks/HD-034.md:7`，原 AC41/AC42 见 `tasks/HD-034.md:21`。当前 `packaging/` 与产品 App 尚未存在；本文件描述拟建交付。

## 需求

- **R1 安装**：Windows 11 x64 普通用户可从可信签名 MSIX 安装、启动、卸载；明确 Publisher、支持 OS 下限、.NET/Windows App Runtime/WebView2 的实际依赖与缺失引导。
- **R2 更新**：沿用同一受控主渠道；版本/签名错误、下载失败、包锁定均不破坏当前可用安装。应用和 herdr 的升级相互独立。
- **R3 回滚**：指定上一已验证包与配置备份可恢复；拒绝未经授权的发行人和被篡改产物，不能通过复制旧 EXE 冒充安装回滚。
- **R4 数据与所有权**：更新只在本应用传输/连接安全释放后执行；保留设备 ID、偏好及原配置备份，不停止 daemon/agent，不更新用户 herdr，不删除远端文件。
- **R5 可复现材料**：签名、timestamp、包清单、依赖、hash 和测试环境有完整记录；发布凭据及系统安装行为必须在后续专项授权下进行。

## 前置依赖与范围

原依赖：HD-007（产品工具链/配置）和 HD-021（helper 产物与可信清单）。
任务目录分别为 `.trellis/tasks/09-08-windows-hd-007`、`.trellis/tasks/09-08-windows-hd-021`。
可在其后准备离线打包；最终 AC41/42 还需 HD-019 的生命周期证据、HD-032 的传输取消，以及 HD-033 的候选构建。
候选渠道建议签名 MSIX + App Installer；具体 Publisher/证书/分发 URL 属于本任务执行前的发行决策，不预填假身份或真实远端地址。

不包含商店上架、WinGet 发布、新云更新服务、用户 herdr 自动更新；不兼容未经支持矩阵覆盖的 Windows SKU。本轮只规划，不签名、不安装、不创建远端 release。

## 子任务验收

- [ ] **AC1（R1；贡献原 AC41）**：干净 Windows 11 x64 标准用户按说明安装→首次启动→普通启动→卸载，全部成功；缺 runtime 与离线安装两分支有确定提示，未选择离线发行则文档明确依赖网络。
- [ ] **AC2（R2、R5；贡献原 AC42）**：当前包更新到指定候选包；分别注入断网、错误 Publisher、损坏包、安装失败，当前安装和配置仍可恢复，证据记录失败原因。
- [ ] **AC3（R3、R4；贡献原 AC42）**：从新配置/新包回到上一签名包后设备 ID/会话配置完整；原有 pane 可由独立客户端连接，未执行 server stop 或替换 herdr。
- [ ] **AC4（R4、R5）**：有活动文件作业时明确延后更新或由用户取消自有作业；包内无私钥，预览与稳定数据互不覆盖，卸载选择仅作用于本应用数据。
- [ ] **AC5（R5）**：HD-035/036 收到确切 commit、MSIX/appinstaller/sidecar hash、签名验证结果、安装矩阵和未验证列表。原 AC41/42 由本任务依据安装/回滚证据汇总；HD-035 的后续安全/许可审查决定整体发行门，不作为本任务完成的前提。

## 执行授权

批准本计划不提供证书私钥、分发地址或目标机器操作授权。执行者先完成无外部写的包草案及检查；签名服务、安装/更新/卸载实验和外部渠道操作逐一使用用户已明确授予的目标与范围。无法取得对应证据时保留 not_run，不伪造成功。
