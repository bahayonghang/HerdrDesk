# HD-035 实施与审查步骤

## 开始条件

- [ ] 已批准本任务审查范围；HD-006/031/034 完成，候选包 hash 已冻结。
- [ ] HD-032 文件安全与 HD-033 高输出/资源证据可读取；缺失项进入阻塞清单。
- [ ] 指定独立审查者及隔离 Windows/SSH/文件测试目标；先做离线产物检查，再在授权目标运行测试。

## 顺序

1. [ ] 对候选包解包，列出 NuGet、npm、Cargo、native runtime、字体和图标；与实际锁文件比对多余、遗漏及版本漂移。
2. [ ] 更新既有 licensing-register；维护者决定项目许可和不明确资产的处置后再继续分发核验。
3. [ ] 运行 HD-007 已固定的各生态扫描；记录工具/数据库日期/命令/exit code/原始结果。任何一步失败不得被后续成功覆盖。
4. [ ] 人工复核严重发现的调用路径、入口与实际影响，分配拥有模块的任务，不在审查中偷偷扩展范围修复。
5. [ ] 在 `tests/Integration.Windows/Security/RendererBoundaryTests.cs` 验证 origin、消息、旧 epoch 和能力绕过；对不能自动断言的进程/剪贴板效果安排人工用例。
6. [ ] 在 `tests/Integration.Windows/Security/DiagnosticPrivacyTests.cs` 做 canary 日志/argv/导出检查。
7. [ ] 复用 HD-021/024/032/034 的信任、网络、文件及签名失败实验；每份证据校验 SHA 与实际产物版本。
8. [ ] 修复完成后只复测相关风险及必要集成面，重建包后重核 hash/清单。
9. [ ] 写单一 `evidence/security-release/review.md`；HD-036 引用最终审查而非历史版本报告。

## 命令与结果

现有离线基线 `just ci` 不包含上述 release audit。未来脚本/测试由 HD-007 与本任务建立后，记录其真实命令再运行；不在本计划填入未验证工具版本或伪造扫描结果。

未来 L1：包清单解析、脱敏转换、无效消息拒绝。
未来 L2/L3：实际 WebView/本地进程/SSH/文件/签名边界，在授权隔离环境运行。
扫描需要联网时仅处理项目依赖元数据；不把用户配置、日志或私钥上传扫描服务。

## 结束与回滚

AC1–AC5 完整后交 HD-036。存在已确认可利用严重问题、授权不清、错设备输入、host-key 绕过或任意执行时阻断 stable；撤回候选或禁用相应功能的实际操作另需发布授权。应用级回滚不得停止 herdr/agent。规划阶段不改任何原 AC 状态。
